# Phato - Backend

Este diretório contém o código-fonte da API do Phato.

## Tech Stack Principal
- **Runtime**: Node.js (ES Modules)
- **Framework**: Express.js v5.1.0
- **Banco de Dados**: MongoDB com Mongoose v8.16.4
- **AI**: Google Generative AI (Gemini)

## Setup Inicial

1. Instale as dependências: `npm install`
2. Crie seu arquivo `.env` a partir do `.env.example`.
3. Para rodar em modo de desenvolvimento (com hot-reload): `npm run dev`

Consulte o documento `BACKEND_TECH_STACK.md` na raiz para a arquitetura completa.
